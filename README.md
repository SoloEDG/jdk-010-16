# LUMEN 光学实验室

安装依赖：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`，生产构建：`npm run build`，测试：`npm test`。

Docker 启动：`docker compose up --build`，访问 http://localhost:18110 。

## 透镜模型

透镜支持在两种模型之间切换（选中透镜后在右侧属性面板切换，切换是可撤销操作）：

- **近轴薄透镜（原模型）**：保持原有理想规则，边缘光线同样按焦距偏折，不模拟厚度与像差。
  撤销切换回薄透镜后，光路与原任务结果完全一致。
- **实体透镜**：包含前/后表面曲率半径（R₁、R₂，透镜制造者符号约定）、中心厚度与色散玻璃
  （BK7 / B270 / F2 / SF11，Cauchy 近似色散）。光线按球面解析二次方程求交，
  逐面应用 Snell 折射，可观察真实球差。

两种模型的参数**不保证一一等价**：实体面板给出的“近轴等效焦距”仅为 Lensmaker 公式参考值。

### 求交与物理规则

- 曲面求交区分前表面、后表面与侧壁（圆柱边缘）。
- 全内反射时光线保留在玻璃内部继续追迹，不会被强制穿出；侧壁命中按反射处理。
- 无效实体（曲率无法覆盖口径、边缘自交、厚度不足）会暂停该透镜求交并在画布顶部给出原因，
  调整参数即可恢复。
- 透镜包围盒重叠、近切线入射等场景给出可恢复警告，不阻断其余光路。

### 接收屏

接收屏按真实命中位置绘制彩色光斑，并输出光斑 RMS 半径、E95 包围半径与横向球差
（边缘 1/3 与近轴 1/3 光线的平均落点之差），可直接比较薄透镜理想聚焦与实体透镜球差。

### 精度与性能边界

- 球面/平面均为解析求交，无折线近似误差；器件轮廓以 28 段折线绘制，仅影响显示。
- 每条光线最多追迹 32 次交互，每个光源最多 41 条采样光线，场景最多 80 个器件。
- 每次界面折射施加 4% 功率衰减，色散为教学级 Cauchy 模型，非完整 Sellmeier 多项式。
- 二维截面模型，不模拟绕光轴旋转的三维像散与衍射效应。
